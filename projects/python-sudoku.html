Overview

A fully playable Sudoku game built in Python with Pygame. The project features a dynamic puzzle generator that creates random, guaranteed-solvable boards, real-time move validation, and a polished graphical interface — developed collaboratively using Git and GitHub.

What I Built

  • Core Algorithm & Game Logic — Dynamic grid generator that constructs random Sudoku boards and validates player moves in real time.
  • Interactive GUI Development — Pygame interface with tile inputs, visual error highlighting, and board reset functionality.
  • Collaborative Engineering — Managed shared version control via Git/GitHub, coordinating on codebase architecture, module integration, and bug fixes with teammates.

Key Features

  • Random puzzle generation with guaranteed solvability
  • Real-time input validation and error highlighting
  • Board reset and new game functionality
  • Modular codebase designed for team collaboration
