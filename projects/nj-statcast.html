Live Demo View on GitHub

Overview

NJ Statcast is a data analytics platform that collects, processes, and ranks New Jersey high school basketball teams. I built an end-to-end pipeline — from automated web scraping to a custom ranking algorithm — that evaluates 350+ teams statewide and surfaces insights through interactive visualizations.

What I Built

  • Data Pipeline & Web Scraping — Automated scraper extracting game outcomes, net margins, and pace metrics from NJ.com into a structured database.
  • Algorithmic Ranking Model — Custom NET ranking system evaluating win percentage, strength of schedule (SOS), and net margin. Results correlate strongly with official media rankings like the NJ Athletics Top 20.
  • Data Visualization & Analytics — Interactive web visualizations including Net-vs-Pace scatterplots and conference strength comparisons, translating raw performance metrics into actionable insights.

Impact

The ranking system provides a data-driven alternative to subjective media polls, giving coaches, players, and fans a transparent view of team performance across the entire state.
